## 冒烟场景

> 结果列填 `PASS` / `FAIL`；FAIL 需附截图 + logcat（`adb logcat | grep -E "TouchService|AutoClickService|FloatingManager|GestureExecutor"`）。

| # | 场景 | 操作步骤 | 预期结果 | 结果 |
|---|---|---|---|---|
| 1 | 启动应用 | 打开触控助手 | 主界面显示两项权限状态与「启动服务」按钮；按钮初始置灰 | |
| 2 | 悬浮窗授权 | 点击悬浮窗权限项 → 跳系统设置 → 授予 → 返回 | 返回后悬浮窗状态图标变 ✓ | |
| 3 | 无障碍授权 | 点击无障碍权限项 → 跳无障碍设置 → 启用服务 → 返回 | 返回后无障碍状态图标变 ✓；「启动服务」按钮可用 | |
| 4 | 启动服务 | 点击「启动服务」 | 悬浮控制面板出现（播放/新增/删除/编辑/退出 5 键） | |
| 5 | 添加目标 | 点击「+」 | 屏幕中央出现新触控目标；面板进入编辑模式 | |
| 6 | 拖拽定位 | 编辑模式下拖动目标 | 目标跟手移动，且不越出屏幕边界 | |
| 7 | 单次触控配置 | 点目标设置按钮 → 选「单次触控」→ 填间隔 → 保存 | 设置保存；目标按单次模式就绪 | |
| 8 | 持续触控配置 | 点目标设置按钮 → 选「持续触控」→ 填滑动距离+方向 → 保存 | 设置保存；目标按持续模式就绪 | |
| 9 | 播放 | 退出编辑模式 → 点击播放 | 目标开始自动触控；按钮变为暂停图标 | |
| 10 | 暂停/停止 | 运行中点击播放/暂停键 | 触控停止；目标恢复可拖拽；按钮变回播放图标 | |
| 11 | 删除目标 | 编辑模式下点「-」或目标删除键 | 目标视图移除，服务同步删除 | |
| 12 | 退出确认 | 点击退出键 → 弹确认框 | 确认后服务停止、悬浮窗全部关闭；取消则无变化 | |
| 13 | 重启恢复 | 重新打开应用 → 启动服务 | 此前配置的最多 5 个目标按原坐标/模式/参数恢复 | |
